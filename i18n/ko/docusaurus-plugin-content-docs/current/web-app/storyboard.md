# Storyboard 에디터

> **English**: [Storyboard Editor](/docs/web-app/storyboard)

**Storyboard 에디터** 는 짧은 요청을 바로 완성된 영상으로 바꾸는 가장 빠른 길입니다. 자연어로 원하는 내용을 설명하면 AI 에이전트가 장면별 컴포지션(이미지 프롬프트, 나레이션, 자막, 모션)을 자동 구성합니다.

**위치**: [kvid.ai/storyboard](https://kvid.ai/storyboard)

## 동작 방식

예를 들어 "30초 분량으로 선크림 원리를 설명하는 밝은 톤의 튜토리얼" 같은 프롬프트를 주면 에이전트는:

1. **씬 플래닝** — 씬 개수, 각 씬의 길이·목적 결정
2. **나레이션 작성** — 언어에 맞게 분량 계산 (한국어 ~4자/초, 영어 ~15자/초)
3. **자산 병렬 생성** — kvidAI API로 이미지·영상·TTS 동시 호출
4. **컴포지션 구성** — 배경, 비주얼, 자막, 오디오 트랙을 타임라인에 배치
5. **Video Editor로 인계** — 필요 시 수동으로 다듬고 렌더링

## 프로젝트 목록

`/storyboard` 는 에이전트로 만든 프로젝트들의 목록 페이지이기도 합니다.

- **검색** — 프로젝트 이름 부분일치
- **상태 필터** — 작성중 / 렌더링중 / 완료
- **정렬** — 최신순, 오래된순, 이름 가나다, 이름 역순
- 썸네일은 컴포지션의 첫 이미지에서 자동 추출됩니다.

## 새 프로젝트 만들기

1. **New Project** 클릭
2. 화면 비율 선택 (16:9, 9:16, 1:1, 4:3 등)
3. 프로젝트 이름 입력
4. 빈 컴포지션으로 에디터에 진입. 이제 에이전트에게 요청하거나 수동 편집 가능.

## AI Agent 채팅

에디터의 **채팅 패널** 이 에이전트를 다루는 주 인터페이스입니다.

흔한 요청:
- "K-beauty 스킨케어 브랜드용 1분 인트로 만들어줘."
- "3번 씬을 좀 더 시네마틱하게 바꿔."
- "전체 영상을 30초로 줄이고 핵심 메시지는 유지해."
- "나레이션을 좀 더 캐주얼한 톤으로 재생성해."

에이전트는 진행 단계(플래닝 → 미디어 생성 → 컴포지션)를 스트리밍으로 보여주고, 캔버스가 실시간으로 업데이트됩니다.

### 템플릿

채팅 위의 **템플릿 선택기** 로 음성·톤·씬 스타일을 세트로 적용할 수 있습니다. 기본 프리셋(예: "review-owl", "sod")과 직접 저장한 커스텀 템플릿을 선택할 수 있습니다.

## 프로젝트 액션

각 프로젝트 카드에서 바로 사용 가능한 메뉴:

- **Open** — 에디터 진입
- **Duplicate** — 독립 복제본 생성
- **Share to Gallery** — 공개 갤러리에 스냅샷 게시
- **Delete** — 영구 삭제

## 요금

이미지·영상·TTS 생성에는 일반 API 요금이 적용됩니다. [요금 안내](/docs/pricing) 를 참고하세요.
