# AI 비디오 에디터

> **English**: [AI Video Editor](/docs/web-app/video-editor)

비디오 에디터는 [Remotion](https://www.remotion.dev/) 기반의 브라우저 영상 편집 도구입니다. Storyboard 에이전트가 작업을 끝내면 자동으로 이 에디터로 진입하고, 갤러리에서 임포트한 프로젝트도 여기에서 편집합니다.

**위치**: `https://kvid.ai/editor/{projectId}`

[Storyboard 목록](./storyboard) 에서 프로젝트를 클릭하거나, [갤러리](./gallery) 에서 임포트해 열 수 있습니다.

## 레이아웃

에디터는 세 개의 메인 패널로 구성됩니다.

| 패널 | 내용 |
|------|------|
| **왼쪽 — 콘텐츠 / 레이어** | 자산(이미지·영상·오디오·폰트), 레이어 리스트, 인스펙터 |
| **중앙 — 캔버스 + 타임라인** | Remotion 플레이어와 다중 트랙 타임라인 |
| **오른쪽 — AI 채팅** | Storyboard와 동일한 에이전트 — 편집도 요청 가능 |

## 재생 제어

- Space — 재생 / 일시정지
- 타임라인 클릭으로 시킹
- 플레이어에 루프 토글, 전체화면 버튼

## 타임라인과 트랙

- 다중 트랙 (배경 / 비주얼 / 캡션 / 나레이션 / 음악 등)
- 드래그로 위치 이동, 엣지 드래그로 트림
- 플레이헤드나 다른 아이템 경계에 스냅 인디케이터
- 트랙 단위 음소거 / 숨김

## 아이템 타입

에디터는 다양한 타입을 지원합니다.

- **Text** — 정적 텍스트 레이어 (폰트, 크기, 색상, 스트로크, 섀도우)
- **Image** — 정적 이미지
- **Video** — 영상 클립, 볼륨 페이드·크롭 옵션
- **Audio** — BGM, 나레이션, SFX, 볼륨 페이드
- **Solid** — 단색/그라데이션 배경
- **Captions** — 단어 단위 애니메이션 캡션 (TikTok 스타일)
- **Custom visuals** — 차트, 별점, 가격비교, 섹션 디바이더, 키워드 오버레이, 타임라인 등

## 인스펙터

레이어를 선택하면 오른쪽에 속성이 표시됩니다 — 위치, 크기, 회전, 투명도, 폰트, 텍스트 내용, 카메라 모션(Ken Burns), 애니메이션 프리셋 등. 실시간 반영됩니다.

## Undo / Redo

- Cmd/Ctrl + Z — Undo
- Shift + Cmd/Ctrl + Z — Redo
- 세션 단위 히스토리 유지

## 자막

일반 Text 레이어로 넣거나, **Captions** 로 단어 단위 자동 싱크 자막을 사용할 수 있습니다.

## 저장

- **자동저장** — 편집 후 짧은 debounce(~500 ms) 뒤 서버로 저장됩니다.
- 수동 저장 버튼은 필요 없습니다. 상단 바에 현재 저장 상태가 표시됩니다.

## 렌더링

최종 영상 렌더링은 Remotion Lambda / 전용 렌더 서비스를 통해 제공됩니다. 현재 에디터는 브라우저 프리뷰를 기본으로 하고, 컴포지션 JSON은 서버에 저장됩니다.

## 공유

상단 바의 **Share to Gallery** 로 작업물을 게시할 수 있습니다. 컴포지션과 첫 프레임 썸네일이 스냅샷으로 저장되어 다른 사용자가 임포트할 수 있습니다. 원본 프로젝트의 소유권은 계속 본인에게 있습니다.

## 자주 쓰는 단축키

| 동작 | 단축키 |
|------|--------|
| 재생/정지 | Space |
| Undo | Cmd/Ctrl + Z |
| Redo | Shift + Cmd/Ctrl + Z |
| 선택 항목 삭제 | Backspace / Delete |
| 복제 | Cmd/Ctrl + D |
| 전체 선택 | Cmd/Ctrl + A |

## 요금

편집 자체는 무료이며, 채팅이나 Generate 패널에서 호출하는 AI 작업(이미지 / 영상 / TTS) 에만 크레딧이 차감됩니다. [요금 안내](/docs/pricing) 참고.
