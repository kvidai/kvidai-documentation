# 1. 사이트 설명

![Untitled](%E1%84%80%E1%85%A2%E1%84%87%E1%85%A1%E1%86%AF%E1%84%8C%E1%85%A1%20%E1%84%91%E1%85%A9%E1%84%90%E1%85%A5%E1%86%AF%20%E1%84%89%E1%85%A1%E1%84%8B%E1%85%B5%E1%84%90%E1%85%B3%20%E1%84%80%E1%85%AE%E1%84%89%E1%85%A5%E1%86%BC%20%E1%84%8B%E1%85%A1%E1%86%AB%E1%84%82%E1%85%A2/Untitled.png)

1. HOME - 개발자 포털 홈페이지로 이동합니다.
2. APIs - 구매 가능한 API 목록과 사용 방법등을 볼 수 있습니다.
3. Products - 결제 상품들의 정보를 확인합니다.
4. 마켓 플레이스 - 상품 결제 진행 및 다른 홈팁스 BIZ 상품들을 확인 할 수 있는 홈팁스 마켓으로 이동합니다.
5. 포럼 - 홈팁스 관련 문의 및 메뉴얼들을 확인할 수 있는 포럼 사이트로 이동합니다.
6. 홈팁스 서비스 - 홈팁스에서 운영하는 web 및 안드로이드/ios 서비스를 확인합니다.
7. Sign in - 로그인을 진행합니다.
8. Sign up - 회원가입을 진행합니다.

# 2. 회원가입

1. 개발자 포털 - API 상품을 사용하기 위해선 먼저 개발자 포털 사이트 회원가입이 필요합니다.
아래 링크를 통해 가입하실 수 있습니다.
[https://developers.kvid.ai/signup](https://developers.kvid.ai/signup)
2. 회원가입에 필요한 내용을 입력해주시고 제출을 눌러주시면 입력해주신 이메일로 임시 비밀번호를 보내드립니다.
3. 입력하신 이메일로 온 임시 비밀번호로 로그인 후에 비밀번호를 변경해주세요.
