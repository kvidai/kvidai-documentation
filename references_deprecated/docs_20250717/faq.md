# Frequently Asked Questions

Find answers to common questions about kvidAI's AI services, billing, technical details, and more.

## Getting Started

### What is kvidAI?

kvidAI is a K-pop and K-beauty specialized AI service platform offering advanced video, image, and text generation APIs. Our platform is optimized for creating K-pop style content, K-beauty product imagery, and Korean cultural content.

### How do I get started with kvidAI?

1. Sign up at [console.kvid.ai](https://console.kvid.ai)
2. Get your API key from [developers.kvid.ai](http://developers.kvid.ai)
3. Purchase credits at [kvid.ai.kr](https://kvid.ai.kr/) (Korean payments) or through international payment methods (coming soon)
4. Follow our [Quick Start Guide](/docs/getting-started/quick-start)

### Do I need technical knowledge to use kvidAI?

While our APIs are designed for developers, we also offer user-friendly tools:
- **For developers**: RESTful APIs with code examples in multiple languages
- **For non-developers**: Excel Plugin with RAG AI integration for easy access
- **For enterprises**: Local RAG solutions with full customization

## API and Service Details

### What APIs does kvidAI offer?

- **Video Generation API**: Create K-pop music videos, dance covers, K-beauty tutorials
- **Image Generation API**: Generate K-pop idol images, K-beauty product shots, Korean fashion
- **Text Generation LLM API**: Korean-optimized text generation with cultural context
- **Excel Plugin with RAG AI**: Easy integration for business users
- **Local RAG Solution**: Enterprise-grade on-premise deployment

### What are the API rate limits?

- **Free tier**: 10 requests per minute
- **Basic plan**: 60 requests per minute
- **Pro plan**: 300 requests per minute
- **Enterprise**: Custom limits available

Contact [Discord support](https://discord.gg/wvsecByF) for higher limits.

### Is there a sandbox or test environment?

Yes! All new accounts receive 10,000 free credits for testing. Use these credits to:
- Test all API endpoints
- Experiment with different parameters
- Validate integration before purchasing

### What file formats are supported?

**Video API**:
- Input: MP4, AVI, MOV, WebM
- Output: MP4 (H.264)

**Image API**:
- Input: JPEG, PNG, WebP
- Output: JPEG, PNG, WebP

## Billing and Credits

### How does the credit system work?

- 1 credit = approximately $0.00001 USD
- Credits are deducted based on API usage
- Different APIs consume different amounts of credits
- Check [Credits Policy](/docs/credits-policy) for detailed pricing

### How long do credits last?

- **Purchased credits**: Valid for 365 days
- **Free trial credits**: Valid for 90 days
- **Promotional credits**: Valid for 90 days

**Currently available**:

## K-pop and K-beauty Specific

### Why is kvidAI specialized for K-pop and K-beauty?

Our models are specifically trained on:
- K-pop music videos and performances
- K-beauty product imagery and tutorials
- Korean fashion and cultural content
- Korean language nuances and trends

This specialization provides superior results for Korean cultural content.

### Can I generate content in other styles?

While optimized for K-pop/K-beauty, kvidAI can generate:
- General video content

However, best results are achieved with K-pop/K-beauty related content.

- Automatic translation for optimal results

Yes, you can request account deletion:
