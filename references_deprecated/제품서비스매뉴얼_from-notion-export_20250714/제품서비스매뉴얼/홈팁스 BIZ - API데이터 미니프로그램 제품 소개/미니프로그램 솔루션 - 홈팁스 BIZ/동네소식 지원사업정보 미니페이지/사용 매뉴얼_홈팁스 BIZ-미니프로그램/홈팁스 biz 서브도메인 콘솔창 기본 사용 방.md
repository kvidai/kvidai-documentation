1. **+ Create new entry**
해당 버튼을 누르시면 새 사이트를 만드실 수 있는 창으로 넘어갑니다.
[⚙ 사이트 생성 방법 안내](https://www.notion.so/biz-_api-91d6d5ef4fd34327966aad22bd2941d1?pvs=21)

2. **찾기**
제작한 사이트를 텍스트로 검색하실 수 있습니다.

3. **필터**
조건에 맞는 사이트만 볼 수 있게 설정 할 수 있습니다.

4. **5번 항목에 보여질 내용을 선택합니다.**

선택할 수 있는 내용은 다음과 같습니다.

**banner_image
banner_link
city
createdAt
district
id
logo_url
organization
state
subdomain
updatedAt
village**

5. [**4번](https://www.notion.so/biz-_api-91d6d5ef4fd34327966aad22bd2941d1?pvs=21)에서 선택한 내용을 보여줍니다.**

4.  필터 

● 필터 설정 방법

1. 필터버튼을 클릭합니다 .
2. 첫 번째 드롭다운 목록을 클릭하여 조건을 적용할 필드를 선택합니다.
3. 두 번째 드롭다운 목록을 클릭하여 적용할 조건 유형을 선택합니다.
4. 필터링할 자산 유형에 따른 조건의 경우 세 번째 드롭다운 목록을 클릭하고 포함하거나 제외할 파일 유형을 선택합니다. 
5. 필터 추가 ****버튼을 클릭합니다 .

● 필터 삭제 방법

필터가 활성화되면 **필터** 버튼 옆에 필터가 표시됩니다. 삭제 아이콘을 클릭하여 제거할 수 있습니다

2. **이미지 세부 편집
1.  Delete** 
- 선택한 이미지가 삭제됩니다.
**2. Download**
- 선택한 이미지를 다운 받을 수 있습니다.
**3. Copy link**
- 선택한 이미지의 URL를 복사 할 수 있습니다>
외의 활용도는 **[로고 및 이미지 삽입방법](https://www.notion.so/biz-_api-91d6d5ef4fd34327966aad22bd2941d1?pvs=21)** 을 참고하세요.
**4. Crop**
- 선택한 이미지를 원하는 만큼 자를 수 있습니다.
(사이즈 큰 이미지만 해당이되는듯 ..? 큰 이미지 준비해서 적용해봐야함 ?? )

자를 자산의 편집 버튼을 클릭합니다 .
팝업 창에서 자르기 버튼을 클릭하여 자르기 모드로 들어갑니다.
프레임 크기를 조정하려면 모서리에 있는 핸들을 사용하여 이미지를 자릅니다. 
드래그 앤 드롭으로 프레임을 이동할 수도 있습니다.
자르기버튼을 클릭하여 새 치수를 확인하고 원본 자산을 자르거나 자산을 복제하고 자르도록 선택합니다(즉, 원본 자산을 그대로 유지하면서 새 치수로 복사본 만들기) 또는 자르기 중지 버튼을 클릭하여 자르기 모드를 취소하고 종료합니다.
마침을 클릭하여 파일 변경 사항을 저장합니다.
