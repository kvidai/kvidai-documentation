## 입력 폼 내용

광고 신청을 좌측 메뉴 “이메일 광고 신청” 탭에서 진행 합니다

Email 

- 광고를 집행하는 사람의 email을 입력해 주세요. hometips 마켓에서 이메일 광고 상품을 구매할때 입력한 이메일과 동일해야 합니다.
- 이메일이 다를경우 광고 집행이 안될 수 있습니다.

광고 문구

- 광고 에서 이미지와 함께 이미지 하단에 삽입될 광고 문구 입니다. 최대 150자 까지 입력 가능 하고 이미지등의 삽입은 불가능 합니다.

베너 url 

- 광고에 사용될 이미지의 url을 입력해 주세요. 이미지 파일을 가지고 있을 경우에는 좌측에 있는 Media Library에 이미지를 업로드 한 후 그 이미지 url을 입력해 주시면 됩니다.
- 이미지 업로드 방법 : [이미지 업로드 방법](%E1%84%8B%E1%85%B5%E1%84%86%E1%85%B5%E1%84%8C%E1%85%B5%20%E1%84%8B%E1%85%A5%E1%86%B8%E1%84%85%E1%85%A9%E1%84%83%E1%85%B3%20%E1%84%87%E1%85%A1%E1%86%BC%E1%84%87%E1%85%A5%E1%86%B8%20d194e9522f554accb6ef865cde9340e9.md)

베너 링크 

- 이메일을 통해 발송된 광고 이미지를 클릭했을 때 연결 하고 싶은 사이트 주소를 입력해 주세요. (ex) [https://hometip.so](https://hometip.so) 형식

배너 위치 

- 베너가 삽입되고자 하는 위치를 선택해 주세요. 이메일에는 상단에 2개, 하단에 2개 지면이 존재하고 각각 상/하단 내에서의 위치는 임의로 적용 됩니다. 위치에 따라서 광고 집행이 불가능 한 날짜가 있을 수 있습니다.
- 한명의 광고주는  위치별로 하나의 광고만 사용할 수 있고, 만약 한 위치에 중복으로 광고를 등록 할 경우 하나의 광고만 사용 됩니다.

광고 집행 날짜 입력 

- 광고를 집행 할 날짜를 입력하세요. 한번에 하루만 선택 가능 합니다.

광고 사용 크레딧 입력

- 광고에 사용하고자 하는 크래딧의 양을 선택하세요. 사용 가능한 최대 갯수는 이메일이 발송될 유저풀에 따라서 자동 적용 됩니다.
- 이메일 발송 건당 2 크레딧이 사용 됩니다. (10 크레딧을 입력 할 경우 총 5명의 유저에게 광고가 삽입되어 이메일이 발송됩니다.)
- 이메일 상품 구매 내역이 없을 경우에는 오류가 표시 됩니다.

## 테스트 이메일 발송 방법

- 테스트 메일 발송 클릭 → 테스트 메일을 받고자 하는 이메일 입력 → 발송하기 클릭
- 테스트 메일을 받아볼 이메일은 마켓에서 구매한 이메일과 달라도 괜찮습니다.
- 테스트 메일은  광고가 삽입된 형태나 위치를 확인하는 용도입니다. 테스트 이메일에 포함되어있는 컨텐츠 내용과 제목등 모든 내용은 실재로 유효하지 않은 데이터 일 수 있습니다.
- 테스트에는 내가 입력한 하나의 지면에만 광고만 표시되지만 실제 발송 될때는 다른 지면에도 광고가 존재 할 수 있습니다.

광고 신청 하기

- 내용이 잘 입력되면 광고가 등록되고 설정하신 날짜에 발송되는 이메일에 광고가 노출됩니다.
- 신청하신 목록은 좌측 메뉴 Content Manager → advertisement에서 확인 가능 합니다.

광고 신청 변경 및 취소

- 신청하신 광고를 취소 하고 싶을 경우 좌측메뉴 Content Manager → advertisement에서 삭제하고자 하는 내용을 삭제 하시면 됩니다.
- 이미 신청하신 내용의 광고를 수정하고 싶으실 경우 광고신청 내용을 삭제한 후 “이메일 광고 신청” 메뉴 에서 다시 폼을 입력해 주시기 바랍니다.
