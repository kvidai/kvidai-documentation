# kvidAI 한국어 가이드

K-pop과 K-beauty 콘텐츠 제작을 위한 AI 플랫폼입니다.

## 🚀 빠른 시작

### API 서비스
- [API 서비스 개요](/docs/ko/api-services) - kvidAI API 전체 개요
- [시작하기 가이드](/docs/ko/getting-started) - 첫 API 호출까지

### 주요 서비스
- **Video 생성 AI API** - 텍스트/이미지로 비디오 생성
- **Image 생성 AI API** - K-pop/K-beauty 특화 이미지 생성  
- **Text 생성 LLM API** - 한국어 특화 텍스트 생성
- **Excel Plugin** - Excel에서 AI 기능 직접 사용
- **Local RAG 솔루션** - 온프레미스 AI 솔루션
