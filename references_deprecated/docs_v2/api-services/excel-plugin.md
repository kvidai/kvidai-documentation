# RAG AI 연동 Excel Plugin

kvidAI Excel Plugin은 MS Office Excel 내에서 설치하여 사용할 수 있는 플러그인으로, AI API를 포함한 다양한 외부 API를 활용하여 Excel 파일 내에서 작업 자동화 및 콘텐츠 생성 자동화 워크플로우를 구축할 수 있습니다.

![Excel Plugin 개요](/img/excel-plugin/excel-plugin-overview.png)

## 🎯 주요 기능

### 핵심 기능
- **동영상 생성**: 프롬프트와 이미지를 입력하여 AI 영상 자동 생성
- **콘텐츠 생성**: 마케팅 글, SNS 게시물 등 텍스트 콘텐츠 자동 작성
- **커스텀 AI 실행**: 사용자 정의 AI 기능 활용
- **외부 API 연동**: RAG, Image, Video API 등 다양한 외부 API 활용
- **Excel 콘솔 연동**: Excel 내용을 콘솔로 전송하여 추가 작업 수행

### Excel 수식 기능
Excel의 `=F(x)` 수식 형태로 사용 가능:

- **RUNGPT_TEXT(Text)**: 텍스트 기반 GPT 실행
- **RUNGPT_IMAGE_TO_TEXT(ImageURL)**: 이미지에서 텍스트 추출
- **RUNGPT_ASYNC_RESULT(TaskID)**: 비동기 작업 결과 조회
- **JSON 데이터 가공**: 각종 JSON 형태 데이터 파싱 및 처리 Helper Function

## 💰 요금 및 크레딧

### 과금 방식
**"unit price × 사용량"**만큼 보유 크레딧이 차감됩니다.

- **Function call 단가**: 기능별로 $0.01 ~ $0.1 크레딧 차감
- **가격 차이 요인**: 
  - 클라우드 함수 내 코드 실행 시간
  - 개발 구현 및 유지보수 난이도
  - 외부 리소스 사용 금액 반영

### 요금 예시

**기본 예시:**
- $10 결제 시 → 1실행당 $0.01 function을 1000번 실행 가능
- 예: 10열 × 100행 = 1000회 실행

**복합 함수 예시:**
```excel
=RUN_GPT(PARSE_JSON(B1))
```
- RUN_GPT: $0.01 + PARSE_JSON: $0.05 = **총 $0.06 per 실행**

## 🎬 동영상 생성 기능

Excel에서 **프롬프트**와 **이미지**를 입력하여 AI가 자동으로 영상을 생성합니다.

### 사용 방법
1. **프롬프트 열**: 생성할 동영상에 적용될 프롬프트 입력 (전체 열 또는 A2:A4와 같은 특정 범위)
2. **이미지 프롬프트 열**: 동영상 생성 시 첫 프레임으로 사용되거나 참고할 이미지 경로/주소 입력
3. **출력 파일 열**: 생성된 동영상이 저장될 동영상 이름 입력

### 처리 시간 및 저장
- **생성 시간**: 프롬프트에 따라 1~4분 소요
- **저장 위치**: [콘솔 사이트](https://console.kvid.ai) 미디어 라이브러리에 자동 저장

## 📝 콘텐츠 생성 기능

Excel에 **콘텐츠 작성용 프롬프트**를 입력하면, 각 열에 맞춰 다양한 마케팅 글을 자동으로 생성하는 기능입니다.

### 활용 분야
- SNS 게시물 작성
- 광고 카피 제작
- 제품 설명문 생성
- 마케팅 메시지 작성

### 사용 방법
1. **입력 열**: 콘텐츠를 작성할 때 사용될 프롬프트 입력 (주제, 제목, 태그 등 다양한 정보를 자유롭게 입력)
2. **출력 열**: AI를 통해 입력받은 프롬프트로 생성된 콘텐츠 텍스트를 저장할 Excel 열 지정

## 🔧 커스텀 AI 실행

Excel에서 **프롬프트, GPT 설정** 등을 입력하면, 사용자가 원하는 맞춤형 AI 기능을 자유롭게 활용할 수 있는 기능입니다.

### 설정 항목
- **옵션 설정**: 사용하고자 하는 AI 모델, 서비스 키 등이 입력되어 있는 옵션 선택
- **입력 열**: API 프롬프트를 적용시킬 내용이 들어있는 열이나 범위 입력 (원문 텍스트뿐만 아니라 이미지, 비디오 등 입력 가능)
- **프롬프트 열**: 입력 열에 입력한 원문 콘텐츠에 적용시킬 AI 프롬프트가 입력되어 있는 열
- **출력 열**: 최종적으로 생성된 AI 결과물을 기록할 Excel 열

### 활용 예시
- 텍스트 생성, 데이터 분석, 코드 작성 등 원하는 형태로 커스터마이징된 결과 제공
- 복잡한 AI 활용도 간편하게 자동화
- 업무 효율성 극대화

### 개발 예정 기능

## 💡 사용 사례

### 마케팅 콘텐츠 자동화
```excel
A1: 신제품 런칭 키워드
B1: =RUNGPT_TEXT("A1을 활용한 SNS 마케팅 포스트 작성")
```

### 대량 번역 작업
```excel
A1:A100: 한국어 제품 설명
B1: =RUNGPT_TEXT("A1을 자연스러운 영어로 번역")
```

### 이미지 분석 및 설명 생성
```excel
A1: https://example.com/product-image.jpg
B1: =RUNGPT_IMAGE_TO_TEXT(A1)
```

### 비동기 대량 처리
```excel
A1: 대량 데이터 처리 요청
B1: =RUNGPT_ASYNC_RESULT(A1)
```

### 복합 데이터 처리
```excel
A1: {"title": "제품명", "price": "가격"}
B1: =RUN_GPT(PARSE_JSON(A1))
```
