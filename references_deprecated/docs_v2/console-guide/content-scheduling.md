# 카페 글쓰기 예약 기능

카페 글쓰기 예약 기능은 운영을 위해 일정 주기 및 매일 들어가서 글을 작성해야 하는 불편함을 해결하고자 컨텐츠를 작성하고 날짜를 설정해 놓으면 해당 날짜에 글을 카페에 자동으로 업로드해 주는 스케줄링 서비스입니다.

## Content Manager - 자동 글쓰기 목록

해당 컬렉션에 있는 목록들을 정해놓은 스케줄 날짜에 지정한 카페 게시판에 글쓰기를 진행합니다.

### 필수 입력 항목

| 항목 | 설명 | 필수여부 |
|------|------|----------|
| **activate** | 임시저장인지 실제로 배포할 내용인지 표시 | ✅ |
| **title** | 글 제목 | ✅ |
| **content1~10** | 발행할 글 내용 (텍스트 또는 이미지 URL) | ✅ |
| **sheet** | "시트 배포 정보"에서 등록한 시트 이름 | ✅ |

### 선택 입력 항목

| 항목 | 설명 |
|------|------|
| **directory** | 글 분류 (사용자 임의 지정) |
| **platform** | 글을 발행할 플랫폼 (네이버 카페, 워드프레스 등) |
| **writing_location** | 글 발행할 위치 (사용자 임의 지정) |
| **table** | 카페 글쓰기 할 게시판 고유 ID |
| **post_tag** | 글 태그 |
| **writing_target_url** | 글쓰기를 진행할 카페의 URL |
| **reference_url** | 글 쓸 때 참고한 문서 URL |
| **manager** | 글 작성 담당자 |
| **writer** | 글 작성자 |
| **memo** | 기타 메모 |
| **post_writing_schedule_date** | 글 발행할 날짜 (미입력 시 바로 작성) |
| **user_prompt** | 글 쓰기 처리할 때 사용될 내용 (CSS, 강조 키워드 등) |

## 시트 배포 정보

시트 단위로 설정할 수 있으며, 글 목록에서 sheet1로 설정해놓으면 타겟하는 카페와 게시판을 오프셋해 놓을 수 있습니다.

### 설정 방법
1. 시트 이름 설정
2. 타겟 카페 URL 지정
3. 게시판 ID 설정
4. 배포 옵션 구성

## 카페 글 발행

스케줄링하지 않고 바로 글 작성할 때 사용됩니다.

### 사용 방법
1. "시트 배포 정보"에 등록된 sheet 선택
2. 글쓰기 진행 버튼 클릭
3. 선택한 시트가 적용된 "자동 글쓰기 목록"의 글들이 발행됨

### 발행 조건
- 날짜 입력하지 않은 글
- 당일 날짜에 해당하는 글

## 예상 사용 고객

정기적으로 글을 올려야 하는 카페 운영자를 타겟으로 합니다:

- **학원 카페**: 주간 강의 일정
- **어린이집/식당**: 주간/일간 식단표
- **좋은글 공유 카페**: 오늘의 명언 등
- **맘카페**: 오늘의 동네소식 등 정기적인 정보 공유
