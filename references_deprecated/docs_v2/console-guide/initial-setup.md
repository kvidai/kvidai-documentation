# 콘솔 초기 설정 가이드

kvidAI 서비스를 처음 이용하시는 분들을 위한 단계별 설정 가이드입니다. 계정 생성부터 API 키 발급까지 전 과정을 안내합니다.

## 🚀 시작하기 전에

### 필수 준비사항
- 이메일 주소 (Gmail, Naver 등)
- 휴대폰 번호 (SMS 인증용)
- 크레딧 카드 또는 계좌 (결제용, 선택사항)

### 접속 URL
- **콘솔**: [console.kvid.ai](https://console.kvid.ai)
- **개발자 포털**: [developers.kvid.ai](https://developers.kvid.ai)
- **메인 앱**: [app.kvid.ai](https://app.kvid.ai)

## 📝 1단계: 계정 생성

### 1.1 회원가입

1. [kvidAI 콘솔](https://console.kvid.ai)에 접속
2. **"회원가입"** 버튼 클릭
3. 가입 정보 입력:
   - 이메일 주소
   - 비밀번호 (8자 이상, 영문+숫자 조합)
   - 이름/닉네임
   - 휴대폰 번호

### 1.2 이메일 인증

1. 입력한 이메일로 인증 메일 발송
2. 메일함에서 인증 링크 클릭
3. 인증 완료 확인

### 1.3 휴대폰 인증

1. SMS로 인증번호 발송
2. 6자리 인증번호 입력
3. 인증 완료

:::tip 인증 팁
인증 메일이 오지 않으면 스팸함을 확인해보세요. 5분 이내에 오지 않으면 재발송을 요청하세요.
:::

## 🔑 2단계: API 키 발급

### 2.1 개발자 포털 접속

1. [developers.kvid.ai](https://developers.kvid.ai)에 접속
2. 콘솔 계정으로 로그인

### 2.2 API 키 생성

1. **"API Keys"** 메뉴 선택
2. **"새 API 키 생성"** 버튼 클릭
3. API 키 정보 입력:
   - **키 이름**: 용도를 구분할 수 있는 이름 (예: "블로그 프로젝트")
   - **권한 선택**: 
     - `video:generate` - 비디오 생성
     - `image:generate` - 이미지 생성
     - `text:generate` - 텍스트 생성
   - **사용량 제한**: 월별 크레딧 한도 설정 (선택)

### 2.3 API 키 저장

:::warning 중요
API 키는 생성 시 한 번만 표시됩니다. 반드시 안전한 곳에 저장하세요!
:::

1. 생성된 API 키 복사
2. 안전한 곳에 저장 (비밀번호 관리자 권장)
3. 키가 노출되지 않도록 주의

## 💳 3단계: 크레딧 설정

### 3.1 크레딧 구매

1. 콘솔에서 **"크레딧 관리"** 메뉴 선택
2. 원하는 크레딧 패키지 선택:

| 패키지 | 크레딧 | 가격 | 유효기간 |
|--------|--------|------|----------|
| **스타터** | 100 | 10,000원 | 30일 |
| **베이직** | 500 | 45,000원 | 60일 |
| **프로** | 1,000 | 80,000원 | 90일 |
| **엔터프라이즈** | 5,000 | 350,000원 | 180일 |

3. 결제 방법 선택:
   - 신용카드
   - 계좌이체
   - 무통장입금

### 3.2 자동 충전 설정 (선택)

1. **"자동 충전 설정"** 활성화
2. 최소 잔액 임계값 설정 (예: 50 크레딧)
3. 자동 충전할 패키지 선택

## 👥 4단계: 사용자 권한 설정

### 4.1 팀 멤버 초대 (선택)

조직에서 사용하는 경우:

1. **"팀 관리"** 메뉴 선택
2. **"멤버 초대"** 버튼 클릭
3. 이메일 주소와 권한 레벨 설정:
   - **Admin**: 모든 권한
   - **Developer**: API 사용 및 키 관리
   - **Viewer**: 사용량 조회만

### 4.2 프로젝트 설정

1. **"프로젝트 관리"** 메뉴 선택
2. **"새 프로젝트 생성"** 클릭
3. 프로젝트 정보 입력:
   - 프로젝트 이름
   - 설명
   - 예상 사용량
   - 팀 멤버 할당

## 🧪 5단계: API 테스트

### 5.1 API 테스트 도구 사용

콘솔에서 제공하는 테스트 도구로 API 동작 확인:

1. **"API 테스트"** 메뉴 선택
2. 테스트할 API 종류 선택
3. 간단한 요청 전송
4. 응답 확인

### 5.2 첫 번째 API 호출

**이미지 생성 테스트:**
```bash
curl -X POST "https://api.kvid.ai/v1/image/generate" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "귀여운 고양이",
    "width": 512,
    "height": 512
  }'
```

**텍스트 생성 테스트:**
```bash
curl -X POST "https://api.kvid.ai/v1/chat/completions" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen2.5-72b",
    "messages": [{"role": "user", "content": "안녕하세요"}],
    "max_tokens": 100
  }'
```

## 📊 6단계: 모니터링 설정

### 6.1 사용량 알림 설정

1. **"알림 설정"** 메뉴 선택
2. 다음 알림 활성화:
   - 크레딧 잔액 부족 (예: 20% 남음)
   - 일일 사용량 초과
   - API 오류 발생
   - 요금 청구 알림

### 6.2 대시보드 구성

1. **"대시보드"** 메뉴에서 위젯 구성
2. 중요 지표 추가:
   - 일일/월별 사용량
   - 크레딧 잔액
   - API 응답 시간
   - 오류율

## 🔧 고급 설정

### 웹훅 설정 (선택)

API 이벤트를 외부 시스템으로 전송:

1. **"웹훅"** 메뉴 선택
2. 엔드포인트 URL 입력
3. 이벤트 유형 선택:
   - 작업 완료
   - 크레딧 부족
   - API 오류

### IP 화이트리스트 (보안 강화)

1. **"보안 설정"** 메뉴 선택
2. 허용할 IP 주소 또는 범위 입력
3. API 키별로 다른 IP 제한 가능

## 🆘 문제 해결

### 자주 발생하는 문제

**Q: 인증 메일이 오지 않아요**
- 스팸함 확인
- 이메일 주소 오타 확인
- 5분 후 재발송 요청

**Q: API 키가 작동하지 않아요**
- 키 복사 시 공백이나 특수문자 포함 여부 확인
- 권한 설정 확인
- 크레딧 잔액 확인

**Q: 크레딧이 차감되지 않아요**
- 결제 완료 여부 확인
- 계정 인증 상태 확인
- 1-2시간 후 재확인
