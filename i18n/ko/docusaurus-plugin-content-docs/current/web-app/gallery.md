# 갤러리

> **English**: [Gallery](/docs/web-app/gallery)

**갤러리** 는 완성된 컴포지션을 서로 공유·임포트하는 공간입니다. 다른 사용자의 작업을 템플릿처럼 활용할 수 있습니다.

**위치**: [kvid.ai/gallery](https://kvid.ai/gallery)

## 둘러보기

- **카드 그리드** — 각 카드에 썸네일, 제목, 작성자(이메일 마스킹), 임포트 수, 태그 표시.
- **검색** — 컴포지션 이름 기준 (서버 측, debounce)
- **카드 클릭** — 상세 페이지 열기

## 상세 페이지

`/gallery/{id}` — 단일 컴포지션 페이지:

- **실시간 프리뷰** — 컴포지션이 브라우저에서 직접 렌더링됩니다 (별도 MP4 파일 없음). 클릭해서 재생/정지.
- **제목, 설명, 작성자, 태그 목록**
- **임포트 수** — 이 컴포지션을 시작점으로 사용한 사용자 수
- **"Use this composition" 버튼** — 내 프로젝트로 임포트

클라이언트 측 렌더링이므로 MP4 저장소가 필요 없고, 외부 자산(이미지·영상·오디오)은 컴포지션에 저장된 원본 URL에서 로드됩니다.

## 임포트

1. **Use this composition** 클릭
2. 계정에 새 프로젝트가 생성되고 컴포지션이 복제됩니다.
3. 에디터로 이동 — 편집·이름 변경·렌더링은 자유

임포트는 원본에 영향을 주지 않습니다. 스냅샷 복제본입니다.

## 내 작업 공유

Storyboard 프로젝트 목록이나 에디터 상단의 **Share to Gallery** 로:

1. 설명과 태그(선택) 입력
2. 제출 — 현재 컴포지션의 스냅샷이 게시됩니다.
3. 첫 이미지 자산에서 썸네일이 자동 추출됩니다.

본인이 게시한 항목은 언제든지 **Unshare(삭제)** 할 수 있습니다. 본인 것만 삭제 가능합니다.

## SEO & 공개 페이지

갤러리 항목마다 개별 공개 URL(`kvid.ai/gallery/{id}`)이 있고 sitemap에 포함되어 검색엔진이 인덱싱할 수 있습니다. OpenGraph 메타 태그에 썸네일이 들어가 소셜 공유 미리보기도 지원됩니다.

## 팁

- **태그** 를 구체적으로 달아두면 다른 사용자가 쉽게 발견합니다.
- 컴포지션의 외부 자산은 kvidAI CDN URL을 사용해야 오래 유지됩니다. 비공개/임시 URL은 시간이 지나면 깨질 수 있습니다.
- **첫 이미지** 가 썸네일이 되므로, 프로젝트 앞부분에 좋은 커버 프레임을 배치하세요.
