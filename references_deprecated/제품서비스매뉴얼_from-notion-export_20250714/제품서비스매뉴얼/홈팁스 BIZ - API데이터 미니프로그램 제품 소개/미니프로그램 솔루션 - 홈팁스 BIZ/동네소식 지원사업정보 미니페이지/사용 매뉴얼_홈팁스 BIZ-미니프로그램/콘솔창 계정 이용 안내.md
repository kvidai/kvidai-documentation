# 1. 회원가입

1. 홈팁스 Biz - 미니프로그램을 사용하기 위해선 관리자 회원가입이 필요합니다.
아래 링크를 통해 가입하실 수 있습니다.
[https://forms.gle/bfytXuXxzFvqZ8Hs7](https://forms.gle/bfytXuXxzFvqZ8Hs7)
2. 회원가입에 필요한 내용을 입력해주시고 제출을 눌러주시면 입력해주신 이메일로 임시 비밀번호를 보내드립니다.
3. 입력하신 이메일로 온 임시 비밀번호로 로그인 후에 비밀번호를 변경해주세요.

❗️❗️주의사항

- 회원가입 시 입력하는 이메일은 개발자 포털 사이트([https://developers.hometip.net/](https://developers.hometip.net/))의 아이디 이메일과 반드시 같아야 합니다.
- 이메일은 마켓플레이스에서 구매를 위해 입력해야 하므로 잊어버리지 않게 관리해 주시기 바랍니다.
