# kvidAI 시작하기

> **View in English**: [Getting Started](/docs/intro) | **한국어** (현재 페이지)

**kvidAI** 는 K-pop, K-beauty 콘텐츠 제작에 특화된 AI 생성 플랫폼입니다. 회원가입·크레딧 충전·콘텐츠 생성·API 키 관리 모두 **[kvid.ai](https://kvid.ai)** 한 곳에서 처리합니다.

## 무엇을 할 수 있나요?

### 웹앱 ([kvid.ai](https://kvid.ai))
- **AI Storyboard Editor** — 원하는 영상을 자연어로 설명하면, 에이전트가 장면별 컴포지션을 자동으로 구성합니다.
- **AI Video Editor** — Remotion 기반 에디터: 타임라인, 레이어, 자막, 오디오, 서버 렌더링까지.
- **갤러리** — 커뮤니티가 공유한 컴포지션을 둘러보고 내 프로젝트로 가져올 수 있습니다.
- **Voice Library** — ElevenLabs 음성 검색·미리듣기, Voice ID를 템플릿에 바로 복사.
- **Generate 페이지** — 텍스트→영상, 이미지→영상, 이미지 생성, 이미지 편집, 립싱크 영상을 직접 실행.

### API 서비스 (`https://api.kvid.ai`)
- **Video Generation** — Text-to-Video, Image-to-Video (v1 / v2 / v3).
- **Image Generation** — Nano Banana 기반 이미지 생성.

## 빠른 시작

1. [kvid.ai](https://kvid.ai) 에서 **회원가입** 및 이메일 인증
2. [kvid.ai/credits/purchase](https://kvid.ai/credits/purchase) 에서 **크레딧 구매** ($30 = 3,000 크레딧, 30일 유효)
3. 웹앱을 바로 사용하거나, [kvid.ai/settings/api-keys](https://kvid.ai/settings/api-keys) 에서 **API 키** 발급

자세한 단계는 [빠른 시작 가이드](./getting-started/quick-start) 를 참고하세요.
