## Contetn Manager - site - Create new entry 를 눌러 
커스텀 사이트를 만들 수 있습니다.

![subsite_create_5.jpg](%E1%84%89%E1%85%A5%E1%84%87%E1%85%B3%20%E1%84%89%E1%85%A1%E1%84%8B%E1%85%B5%E1%84%90%E1%85%B3%20%E1%84%8E%E1%85%AE%E1%84%80%E1%85%A1%20%E1%84%87%E1%85%A1%E1%86%BC%E1%84%87%E1%85%A5%E1%86%B8/subsite_create_5.jpg)

1. subdomain - 서브도메인 입력창입니다. 
* 꼭영어로만 입력해주세요. 한글이나 특수문자가 들어가면 안 됩니다.

2. logo_url - 로고 이미지 url 주소 입력창
3. banner_image - 사이트 메인 배너 변경창
4. banner_link - banner_image 클릭시 이동 할 사이트 주소 입력창

5. state - 특별시/광역시/특별자치시/도/특별자치도의 법정동코드 입력창입니다.
6. city - 시/군/구 법정동코드 입력창입니다.
7. district - 읍/면/동 법정동코드 입력창입니다.
8. village - 리 법정동 코드 입력창입니다.

* 필요 없는 부분의 입력창은 빈칸으로 남겨주시면 됩니다.
* 법정동 코드 검색 안내 ↓
[https://www.code.go.kr/stdcode/regCodeL.do](https://www.code.go.kr/stdcode/regCodeL.do)

위의 항목 입력 후 subdomain에 입력하신 [내용].hometip.so를 입력하시면 사이트에 접속 하 실수 있습니다.

9. organization - 이메일을 보낼 때 사용되는 기관명 입력창입니다.

10. email_header - 이메일 상단부분에 커스텀 입력 할 수 있는 창입니다.
* 입력창은 HTMl로 구성되어있으며 텍스트나 이미지도 삽입 가능합니다.

11. email_footer - 이메일 하단부분에 커스텀 입력 할 수 있는 창입니다.
* 입력창은 HTMl로 구성되어있으며 텍스트나 이미지도 삽입 가능합니다.
