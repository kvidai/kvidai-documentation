## LLM API (Chat Completions)

실제로 사용한 토큰만큼 크레딧이 차감됩니다. 가격은 1,000 토큰당 크레딧입니다.

| 모델 | 입력 | 출력 (reasoning 포함) | 캐시된 입력 (읽기) | 캐시된 입력 (쓰기) |
|------|------|----------------------|--------------------|--------------------|
| `openrouter/openai/gpt-6-luna` | 0.012 | 0.06 | 0.0012 | 0.015 |

- 호출 하나의 차감은 0.01 크레딧 단위로 올림합니다 (성공한 호출은 최소 0.01 크레딧).
- reasoning 토큰은 출력 토큰으로 셉니다.
- 실패한 호출은 차감하지 않습니다.
- 호출 방법: [LLM API](/ko/docs/api-services/llm-api).
