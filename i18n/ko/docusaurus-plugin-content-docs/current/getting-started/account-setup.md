# 계정 설정

> **English**: [Account Setup](/docs/getting-started/account-setup)

## 회원가입

1. [kvid.ai/register](https://kvid.ai/register) 이동
2. 아래 정보를 입력합니다.
   - **사용자명** — 원하는 핸들명
   - **이메일** — 인증 메일이 발송되므로 실사용 주소 필수
   - **비밀번호** — 8자 이상, 대문자 / 소문자 / 숫자 포함
   - **비밀번호 확인**
   - 이용약관 동의
3. **회원가입** 버튼 클릭

## 이메일 인증

- 이메일 인증이 완료되어야 로그인할 수 있습니다.
- 받은 kvidAI 메일의 인증 링크를 클릭하세요.
- 메일이 오지 않았다면 [kvid.ai/auth/resend-verification](https://kvid.ai/auth/resend-verification) 에서 재발송 요청.

인증이 완료되면 확인 페이지로 이동하고 바로 로그인할 수 있습니다.

## 로그인

1. [kvid.ai/login](https://kvid.ai/login) 이동
2. 이메일(또는 사용자명)과 비밀번호 입력
3. 대시보드 [kvid.ai/dashboard](https://kvid.ai/dashboard) 로 이동합니다.

## 비밀번호 재설정

- [kvid.ai/auth/forgot-password](https://kvid.ai/auth/forgot-password) 에서 이메일 입력 → 재설정 링크 수신
