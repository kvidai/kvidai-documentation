# 계정 생성 및 초기 설정

kvidAI 서비스를 이용하기 위한 계정 생성 및 초기 설정 방법을 안내합니다.

## 1. 계정 생성

### 필수 회원가입 사이트
- **Developer Portal**: [developers.kvid.ai](http://developers.kvid.ai) - API 키 발급
- **Console**: [console.kvid.ai](https://console.kvid.ai) - 서비스 관리 및 설정

:::warning 중요
두 사이트의 이메일 주소는 **반드시 동일**해야 합니다.
:::

## 2. API 키 발급

1. [Developer Portal](http://developers.kvid.ai)에 로그인
2. 원하는 API 서비스 선택
3. API 키 발급 신청

## 3. 콘솔 설정

1. [Console](https://console.kvid.ai)에 로그인
2. 크레딧 설정 (직접 설정 필요)
3. 사용자 역할을 `api-user`로 할당

:::info 참고
콘솔 설정은 Cafe24를 거치지 않기 때문에 수동으로 설정해야 합니다.
:::

## 4. 서비스 이용 준비 완료

계정 생성과 설정이 완료되면 다음 서비스들을 이용할 수 있습니다:

- **Video 생성 AI API**
- **Image 생성 AI API**  
- **Text 생성 LLM AI API**
- **RAG AI 연동 Excel Plugin**
- **Local RAG 솔루션**
