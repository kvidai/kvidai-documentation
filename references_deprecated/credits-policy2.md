# Credits Policy

## 1. What are Credits?

Credits are kvidAI's virtual currency designed to provide flexible access to our AI services. They enable users to:
- Access AI generation features across our platform
- Pay only for what you use
- Take advantage of promotional offers and discounts

**Important**: Credits are a platform service, not a payment method, token, cryptocurrency, or prepaid voucher. Credits have no monetary or prepaid value outside the kvidAI platform.

## 2. Credit Types and Acquisition

### Credit Categories

| Type | How to Acquire | Validity Period |
|------|----------------|-----------------|
| **Promotional Credits** | Platform promotions, events, new user bonuses | 90 days from acquisition |
| **Membership Credits** | Monthly allocation with active subscription | 30 days from distribution |
| **Purchased Credits** | Direct purchase via payment portal | 365 days from purchase |

### Free Trial Credits
- New users receive **10,000 free credits** upon registration
- Valid for 90 days
- Perfect for testing all API features before purchasing

## 4. Credit Consumption Rates

### Video Generation API

|---------|-------------------|
| Text-to-Video (5 seconds) | 50,000 credits |
| Text-to-Video (10 seconds) | 100,000 credits |
| Image-to-Video (5 seconds) | 40,000 credits |

### Image Generation API
| Feature | Credits per Request |
|---------|-------------------|
| Standard Image (512x512) | 5,000 credits |
| HD Image (1024x1024) | 10,000 credits |
| 4K Image (2048x2048) | 20,000 credits |
| Style Transfer | 8,000 credits |

### Text Generation API
| Feature | Credits per Request |
|---------|-------------------|
| Standard Generation (up to 1K tokens) | 1,000 credits |
| Extended Generation (up to 4K tokens) | 4,000 credits |
| Korean-optimized Model | 1,500 credits per 1K tokens |

### Failed Generation Policy
- **Successful generation**: Full credits deducted immediately
- **Failed generation**: Credits deducted based on "server instance time × hourly rate"
- Server resources (GPU, CPU) are consumed even for failed attempts
- Deduction will not exceed the standard rate for that feature

## 5. Credit Usage Order

Credits are consumed based on validity period:
1. **Shortest validity first**: Credits expiring soon are used first
2. **Same validity**: Promotional → Membership → Purchased credits
3. **Automatic deduction**: System handles credit selection automatically

## 8. Important Policies

### Non-Transferable
- Credits cannot be transferred between accounts
- No gifting or sharing of credits
- Credits are bound to the purchasing account

### Non-Refundable
- Used credits cannot be refunded
- Unused credits refundable within 7 days of purchase only
- Expired credits are non-refundable

### Account Termination
- Credits expire upon account deletion
- No refunds for remaining credits
- Download all generated content before deletion
