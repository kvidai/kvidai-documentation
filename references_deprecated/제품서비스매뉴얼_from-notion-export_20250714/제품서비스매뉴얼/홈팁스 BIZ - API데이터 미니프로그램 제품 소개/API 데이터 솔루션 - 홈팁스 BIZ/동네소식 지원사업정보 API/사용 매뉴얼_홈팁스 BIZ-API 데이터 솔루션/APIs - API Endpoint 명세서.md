# api 테스트 해보기

---

![Untitled](APIs%20-%20API%20Endpoint%20%E1%84%86%E1%85%A7%E1%86%BC%E1%84%89%E1%85%A6%E1%84%89%E1%85%A5/Untitled%202.png)

1. Authrization - 테스트 해 볼 인증 key를 선택합니다. 일부 endpoint에서는 인증 key에 따라서 response되는 data가 달라집니다.
2. parameters - 파라미터를 입력합니다. 파라미터에 대한 정보는 endpoint 상세 명세에서 확인해 주세요.
3. Headers - 테스트 해 볼 header를 입력합니다. api-key에는 테스트를 위해 임실 발급한 key가 입력되어 있습니다. 실제 사용시에는  api 제품 구매 후 발급받은 개인 key를 입력하시면 됩니다.
4. body - 테스트 해 볼 body를 입력합니다. 입력하는 body의 형태는 제품의 상제 명세를 확인해주세요.
5. HTTP request - 테스트 해 볼 Request의 정보입니다.
6. Send - 테스트 request를 전송합니다. 클릭하시면 Response 정보를 확인 할 수 있습니다.
