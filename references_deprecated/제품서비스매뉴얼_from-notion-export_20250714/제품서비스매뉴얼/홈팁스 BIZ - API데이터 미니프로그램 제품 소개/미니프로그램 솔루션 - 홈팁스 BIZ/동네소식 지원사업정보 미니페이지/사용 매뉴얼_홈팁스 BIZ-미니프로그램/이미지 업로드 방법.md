좌측 Media Library에서 이미지 등록을 할 수 있습니다.

- “Add new assets”을 클릭한 후 이미지를 드래그 해서 올려 놓거나 검색해서 이미지를 업로드 할 수 있습니다.

업로드한 이미지 상세 보기

- Assets 리스트에서 이미지를 클릭하면 이미지의 자세한 정보를 확인 할 수 있습니다.
- 광고나 서브도메인에 사용될 이미지의 link url은 이미지 상단의 링크 아이콘을 통해 복사하실 수 있습니다.
