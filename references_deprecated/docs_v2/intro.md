# kvidAI 문서 시작하기

**kvidAI**는 K-pop, K-뷰티 특화 AI 생성 서비스 플랫폼입니다. 

## 🚀 주요 서비스

### AI 생성 서비스
- **Video 생성 AI API** - AI 기반 비디오 생성
- **Image 생성 AI API** - AI 기반 이미지 생성  
- **Text 생성 LLM AI API** - 대화형 AI 텍스트 생성
- **RAG AI 연동 Excel Plugin** - Excel 연동 RAG AI

### 추가 솔루션
- **Local RAG 솔루션** - 로컬 환경 RAG 서비스
